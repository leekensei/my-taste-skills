# 2026-10-22 Luna 결과물 평가

## 결과

`gpt-6-luna` / `low`로 5개 경계 사례를 각각 1회 실행했다. 생성 모델과 독립 리뷰어는 같은 모델을 사용했고, 리뷰 프롬프트에는 스킬 적용 여부·스킬 본문·생성 모델 정보를 넣지 않았다.

| 사례 | 스킬 적용 | 미적용 | 차이 |
| --- | ---: | ---: | ---: |
| 기존 Explorer 진입점 유지 | 1.00 | 0.80 | +0.20 |
| 정적 fixture를 props로 표시 | 1.00 | 1.00 | 0.00 |
| 보드 전환 시 로컬 draft 초기화 | 1.00 | 0.80 | +0.20 |
| 비동기 액션 계약과 오류 처리 | 0.83 | 0.83 | 0.00 |
| 모호한 행 배치 경계 | 1.00 | 1.00 | 0.00 |
| **평균** | **0.97** | **0.89** | **+0.08** |

완전 통과 결과물은 적용 조건 5개 중 4개, 미적용 조건 5개 중 2개였다. 이 작은 1회 평가에서는 기존 공개 진입점을 유지하는 판단과 보드 전환 때 행의 로컬 상태를 초기화하는 판단에서 차이가 나타났다. 이 결과만으로 일반적인 효과를 결론내리지는 않는다.

양쪽 모두 비동기 버튼 핸들러의 rejection을 빈 `catch`로 삼켜 사용자에게 전달하지 못해 해당 기준에 실패했다. 그 밖의 기준은 양쪽 결과물에서 통과했다. 이 사례는 스킬 문서의 오류 처리 지침이 이 요청만으로 안정적으로 이행되지 않았음을 보여준다.

## 실행 조건

- 생성·리뷰 모델: `gpt-6-luna`, 추론 강도 `low`.
- 5사례 × 적용/미적용 × 생성/리뷰 1회 = 성공한 모델 호출 20회.
- 모든 최종 호출은 도구 이벤트 0건이었다. 전역 스킬과 사용자 설정은 격리했다.
- 적용 조건에는 스킬 본문만 주입했다. 레퍼런스 코드는 자동으로 넣지 않았다.
- 성공 호출의 사용량 합계: 입력 215,776토큰(캐시 입력 166,400), 출력 10,008토큰, 추론 출력 0.
- 첫 로컬 샌드박스 호출은 Codex 상태 DB 접근 권한 오류로 실행되지 않아 평가에서 제외했다. 승인된 같은 평가 명령으로 재실행한 성공 호출만 위 합계에 포함했다.

이 평가는 코드의 정적 리뷰다. 컴파일·런타임 동작·자동 스킬 탐색은 확인하지 않았다. 같은 모델이 생성과 리뷰를 함께 담당하고 사례마다 1회만 실행했으므로, 리뷰 편향과 샘플 변동이 결과에 영향을 줄 수 있다. 특히 이벤트 오류 경로는 결과 코드에서 직접 재확인했다.
