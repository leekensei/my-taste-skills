# React 합성 설계

props로 시작한다. 실제 사용 문제를 해결하는 가장 작은 경계를 선택한다.

| 문제 | 선택 |
| --- | --- |
| 작고 안정적인 API | props |
| 배치 변화 | 호출부 조립형 컴포넌트 |
| 동일 UI의 교체 데이터 출처 | 공통 계약과 provider |
| 형제 간 공유 상태·액션 | 공통 상위 provider, 말단 상태는 로컬 |
